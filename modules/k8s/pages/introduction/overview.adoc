= TigerGraph Operator Overview

[IMPORTANT]
====
Operator versions prior to 1.5.0 relied on the Docker image
`gcr.io/kubebuilder/kube-rbac-proxy` to secure the metrics endpoint.

This image will no longer be available after May 2025.

Starting from version 1.5.0, the Operator uses the Docker image
`quay.io/brancz/kube-rbac-proxy`.

To avoid image pull errors, upgrade the Operator to version 1.5.0 or later.
====

TigerGraph Operator is an automated operations system designed to manage
TigerGraph clusters in Kubernetes environments.

It supports the full TigerGraph lifecycle, including deployment, upgrades,
scaling, backups, restore, and failover. The Operator works in both public
cloud and self-managed Kubernetes clusters.

[NOTE]
====
Kubernetes Operator support is generally available starting with Operator
version 1.1.0 and can be used for production deployments.
====

[IMPORTANT]
====
TigerGraph Operator introduced a breaking change in version 1.0.0.

If you are using a version earlier than 1.0.0, upgrade to version 1.2.0 or
later. Versions older than 1.0.0 are deprecated.
====
